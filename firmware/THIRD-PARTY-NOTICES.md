## Notes

- **SLA0044:** the STM32 USB Device Library may only be used with, and redistributed for use with, microcontrollers manufactured by or for STMicroelectronics. This firmware runs on an STM32F070CB.
- **Changes to the Custom HID class:**
  - the endpoint size is 64 bytes;
  - class requests are rejected while the class isn't initialized;
  - `SET_REPORT` requests longer than the report buffer are rejected.
- **Changes to the generated files:** they are limited to the USER CODE sections, except for the files moved to `Drivers/USB` (see [README.md](README.md#regenerating-the-code-in-stm32cubemx)).
