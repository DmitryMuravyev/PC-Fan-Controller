# Contributing

Thank you for your interest in Fan Controller!

## Bug reports and feature requests

Bug reports and feature requests are welcome for every part of the project:
the firmware, the service, the application and the hardware. Please use the issue
forms (*Issues* → *New issue*) and choose the component in the form.

- **Bug report**: include the firmware version and, depending on the component:
  - firmware: what the display, the error LED and the buzzer show, and, if possible,
    the UART log (see [firmware/README.md](firmware/README.md#build-options));
  - service / application: the software version, your operating system and the
    relevant part of the service log (see [software/README.md](software/README.md#configuration));
  - hardware: the board revision, the power option used and the connected fans
    and sensors.
- **Feature request**: describe the problem the feature would solve.

Please check the existing issues first.

## Pull requests

Code contributions (pull requests) are **not accepted at the moment**, while the
project is in its early stage. Pull requests may be closed without review.
If you have an idea or a fix, please open an issue and describe it instead.

## Security issues

Please don't report security vulnerabilities in public issues; see
[SECURITY.md](SECURITY.md).
